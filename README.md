# S.A.M.

Systems Administration & Maintenance — an original industrial control console inspired by the **interaction principles** of *Observation*. No game assets are included.

Flutter iOS client + FastAPI/PostgreSQL service. A shared 42-node simulation supports up to five concurrent operators, with SCAN → LINK → CONTROL, facility/network maps, camera HUDs, fault propagation, alerts and audit logs.

All compilation and automated verification run in **GitHub Actions**. The workflow publishes an **unsigned IPA** and a **Docker image archive / Ubuntu deployment package**. Signing, installation and deployment are manual.

Source: `server/src/sam/`, `client/lib/`. Native iOS/Android boilerplate is generated by the pinned Flutter SDK in CI; project-specific native settings are versioned in `scripts/native_projects.py`, and generated native projects accompany the iOS artifact. This makes CI the sole build environment while keeping platform configuration reproducible and reviewable.

The camera scenes and detections are explicitly simulated. This release contains no real AI, physical device adapters, real video streaming, or automation engine. The name is an internal, replaceable identity; the app icon is the generated placeholder pending original branding.
