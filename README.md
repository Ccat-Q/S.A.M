# S.A.M.

Systems Administration & Maintenance — an original industrial control console inspired by the **interaction principles** of *Observation*. No game assets are included.

Flutter iOS client + FastAPI/PostgreSQL service. A shared 42-node simulation supports up to five concurrent operators, with SCAN → LINK → CONTROL, a station relocation map, separate network topology, original mock CCTV scenes, device-specific terminals, fault propagation, anomaly analysis, audit logs and a read-only memory relation ring.

All compilation and automated verification run in **GitHub Actions**. The workflow publishes an **unsigned IPA** and a **Docker image archive / Ubuntu deployment package**. Signing, installation and deployment are manual.

Source: `server/src/sam/`, `client/lib/`. Native iOS/Android boilerplate is generated by the pinned Flutter SDK in CI; project-specific native settings are versioned in `scripts/native_projects.py`, and generated native projects accompany the iOS artifact. This makes CI the sole build environment while keeping platform configuration reproducible and reviewable.

The two original prerendered camera scenes and detections are explicitly simulated; their provenance is recorded in `client/assets/camera/PROVENANCE.md`. Memory Ring is a read-only projection of existing events, nodes and edges. This release contains no real AI, physical device adapters, real video streaming, or automation engine. The name is an internal, replaceable identity; the iOS system mark is original vector geometry rasterized in CI.
